# NARaz backend

Backend и blockchain/testnet логика из v1.1/v1.3 сохраняются. В эту версию добавлен реальный поток рыночных данных без симуляции цен:

- Binance WebSocket: ticker, top-20 depth и 1h kline.
- Binance REST используется только для первоначального заполнения/резерва.
- NARaz Network раздаёт полученные события своим клиентам через собственный WebSocket.
- Market order исполняется по текущей полученной внешней цене; само расчётное исполнение остаётся внутри NARaz Exchange Testnet.

Backend остаётся тестовой централизованной сетью, а не production blockchain: перед реальным запуском нужны HTTPS, криптографические подписи, защищённое хранение ключей, P2P/консенсус, rate limiting, аудит и юридическая проверка.
